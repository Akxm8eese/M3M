# Contract boundary
The schema covers the minimum reviewed public content index. foodIds reference
an implementation-owned food catalog; the supplied validator cannot validate
that external catalog. Before implementation is complete, extend the contract
and validator to include foods (portion, preparation, allergens, nutrients,
claimIds), coordinate manifests, source URLs and date validation, and asset
file/rights-document existence. These are required integration tasks B02/B03.
No actual prototype claim is marked approved by this kit. Do not use fabricated
reviewer names or seed records to bypass the content gate.
